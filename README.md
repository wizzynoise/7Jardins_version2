# 7 Jardins — website empresarial

Projeto de website desenvolvido para uma empresa de jardinagem e preservado como peça de portefólio.

## Sobre o projeto

Este repositório contém uma versão pública do trabalho realizado para o projeto 7 Jardins. O site original já não está ativo porque a empresa encerrou, mas o código é mantido como registo de uma experiência de desenvolvimento web e de evolução de interface.

## O que este projeto demonstra

- construção de uma interface responsiva;
- organização de páginas e componentes em React;
- utilização de TypeScript, Tailwind CSS e Vite;
- adaptação de uma necessidade empresarial para uma experiência web clara.

## Tecnologias

React · TypeScript · Tailwind CSS · Vite

## Estado

Projeto histórico de portefólio. Não está em desenvolvimento ativo e não existe uma demo pública ativa.

## Nota

O projeto foi desenvolvido com apoio de ferramentas de prototipagem e desenvolvimento assistido. O repositório é apresentado como parte do percurso e do trabalho realizado, não como um produto atualmente mantido.
